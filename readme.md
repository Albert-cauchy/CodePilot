# CodePilot

CodePilot is a coding agent built with LangGraph. It uses Docker to execute tasks and collect patches and complete execution trajectories. The main agent has seven tools: `read`, `edit`, `write`, `shell`, `finish`, `think`, and `delegate`. Subagents have the first six tools.

`think` saves the plan generated by the current model. `delegate` runs independent subtasks in parallel, each with the same repository snapshot and its own context. All repository writes by subagents, including those made through shell commands, must pass file authorization checks.

## Installation

Python 3.10+, a local Docker daemon, and Linux FUSE 3 (`/dev/fuse`, `fusermount3`, and `libfuse3`) are required. Subagents use a FUSE proxy on the host, so remote Docker daemons are not supported. Subtasks are rejected if execution-level permission enforcement is unavailable.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev,evaluation]'
```

## Running

The development runner connects to `http://localhost:8000/v1` by default. You can also use a custom API endpoint:

```bash
python -m scripts.run_dev --limit 1 --max-model-calls 20 --max-parallel-subagents 4
python -m scripts.analyze_dev
```

`--max-model-calls` sets the model-call threshold. Subtasks that have already started do not stop when the threshold is reached. Once the entire batch returns, the main agent performs one final analysis without tools and then exits. The actual number of model calls can therefore exceed the threshold. `finish` indicates that the agent has voluntarily ended its work.

## Trajectories

All agent trajectories are stored under `trajectory/` by default. Use `--trajectory-dir` to specify a different root directory:

```text
trajectory/
  failures.jsonl
  evaluation.jsonl
  <task-id>/
    attempt-<attempt>-<unique-id>/
      events.jsonl
      plan.md
      subagents/<subtask-id>/
        events.jsonl
        plan.md
        report.json
        changes.json
        patch.diff
```

Plans are created or updated only when the model calls `think`. `changes.json` stores content deltas that can be reconstructed exactly; `patch.diff` is intended for human review. If a subagent's model fails, its partial changes are retained as artifacts and are not automatically applied. Main-agent and subagent trajectories are linked by run IDs, subtask IDs, and parent tool-call IDs. Actual model inputs and outputs are always recorded.

Predictions and evaluation results are stored under `outputs/dev/` by default. The analysis script summarizes a single run and the actual costs of all its subagents.

## Validation

```bash
python -m pytest tests -q
python -m mypy codepilot scripts
```

File permission tests create temporary FUSE mounts and require host access to `/dev/fuse`. Docker integration tests are skipped by default. To test actual containers, specify an existing local image that includes Python and Git:

```bash
CODEPILOT_DOCKER_TEST_IMAGE=<local-image> python -m pytest tests/test_docker_subagents.py -q
```
